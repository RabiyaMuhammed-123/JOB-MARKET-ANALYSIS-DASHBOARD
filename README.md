Job Market Analysis Dashboard | Power BI

📌 Project Overview

This project focuses on analyzing job market data using Microsoft Power BI to understand job opportunities, salary trends, industry demand, experience levels, educational requirements, and in-demand technical skills.

The dashboard transforms job market data into meaningful visual insights through data cleaning, analysis, and interactive visualizations.

🎯 Objectives

- Analyze job distribution across industries and cities.
- Explore applicant trends by experience level.
- Compare average salaries across industries and experience levels.
- Identify popular job roles and in-demand technical skills.
- Analyze educational qualifications and work mode distribution.

🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
- Data Modeling

📊 Dashboard Features

- Key performance indicators (KPIs)
- Job distribution by industry and city
- Applicant analysis by experience level
- Salary comparison by industry and experience
- Top 10 job roles
- In-demand technical skills analysis
- Educational qualification analysis
- Work mode distribution

🔍 Key Insights

- Information Technology recorded the highest job count among the displayed industries.
- Python was the most frequently demanded skill in the dashboard.
- Software Engineer was the most represented role among the top 10 job titles.
- B.Tech/B.E. was the most frequently represented educational qualification.
- Lead-level positions recorded the highest average salary among the displayed experience levels.
- On-site roles accounted for 39.8% of jobs, followed by Hybrid at 34.7% and Remote at 25.5%.
